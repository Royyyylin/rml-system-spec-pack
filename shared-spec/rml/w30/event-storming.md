# Event Storming — W30: Fleet Broadcast + WebSocket Push

> Wave: App Wave 30
> Source: `w30-01-fleet-broadcast.md`, `w30-02-auto-grouping.md`, `w30-03-websocket-push.md`

## Domain Events

| Event | Trigger | Actor | Outcome |
|---|---|---|---|
| `FleetCommandDrafted` | Engineer creates new broadcast command | App | `FleetCommand` in `draft` state |
| `BroadcastConfirmed` | Engineer confirms in confirmation dialog | App | Command moves to `confirmed` state |
| `BroadcastDispatched` | `BroadcastEngine` sends to Central API | App | Command moves to `dispatched`; batch pages sent |
| `DeviceAcked` | Central receives ack from GW | Central → App | Per-device status updated to `acked` |
| `DeviceTimedOut` | 30s elapsed without ack | App | Per-device status `timeout` |
| `BroadcastPartial` | Some devices acked, some timed out | App | Command in `partial` state |
| `BroadcastComplete` | All devices acked | App | Command in `complete` state |
| `BroadcastFailed` | Critical failure (network, rate-limit) | App | Command in `failed` state |
| `RollbackAutoGenerated` | `profile_switch` broadcast completed | App | Rollback command available for one-tap undo |
| `RateLimitHit` | Second broadcast within 30s attempted | App → Central | Error response; App shows rate-limit warning |
| `AutoGroupRulesFetched` | App sync pulls rules from Central | App | `AutoGroupRule` entities cached locally |
| `GroupMembershipSynced` | 29A sync engine runs | App | `GroupMembershipCache` updated |
| `GroupCacheStale` | >5min since last sync | App | Staleness badge shown in group UI |
| `WebSocketConnected` | App establishes WS connection | App | Real-time push events begin |
| `DeviceStateEventReceived` | Central pushes state change | App WS client | UI refreshed without manual pull |
| `AlertEventPushed` | Central pushes alert | App WS client | Alert shown in relevant UI |

## Commands

| Command | Actor | Wire/API |
|---|---|---|
| `BroadcastEngine.dispatch(command, group)` | App | REST POST to Central broadcast endpoint |
| `BroadcastRateLimiter.check()` | App (pre-dispatch) | local guard + server-side enforcement |
| `GroupRuleRepository.fetchRules()` | App | REST GET from Central auto-group API |
| `GroupSyncService.sync()` | App (29A engine) | incremental sync via 29A SyncEngine |
| `WebSocketClient.connect(url, token)` | App | WS handshake to Central push server |

## Aggregates

| Aggregate | State | Invariant |
|---|---|---|
| `FleetCommand` | draft → confirmed → dispatched → partial/complete/failed | No skip from draft → complete; transitions enforced |
| `BroadcastEngine` | batch state + per-device ack map | Dispatches in ≤100 device pages |
| `GroupMembershipCache` | members per group + last_sync | Read-only; staleness tracked; invalidated on org switch |
| `WebSocketClient` | connection state + event queue | Must reconnect on disconnect; does not block UI thread |
