event / alarm 不會跟著此處的 slow cadence 走，仍保持 event-driven。
原則
  • connection interval 與 packet send interval 受 ED 數量明顯影響，多 ED 應放寬
  • supervision timeout 會跟著 link 壓力與 interval 一起放寬（中度間接影響）
  • event / alarm 不跟著慢 cadence，保持 event-driven
