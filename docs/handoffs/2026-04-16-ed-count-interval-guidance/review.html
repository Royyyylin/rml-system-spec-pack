ED-count guided interval recommendation
Engineer / 佈場用 guided guidance，不是 runtime patrol 主畫面。
依「Power class」與「同時連線 ED 數」建議三個值：BLE connection interval、packet send interval、supervision timeout。
Power class
Connected ED count
建議值
依 Power class 與 ED 數量自動套用
Powered · 1–3 ED
BLE connection interval
100 ms
較快回應，適合少量 ED
Packet / data send interval
100–200 ms
適合 powered device 的即時更新
Connection supervision timeout
4–6 s
避免短暫干擾就誤判斷線
原則
  • connection interval 與 packet send interval 受 ED 數量明顯影響，多 ED 應放寬
  • supervision timeout 會跟著 link 壓力與 interval 一起放寬（中度間接影響）
  • event / alarm 不跟著慢 cadence，保持 event-driven
