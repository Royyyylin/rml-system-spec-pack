Advanced wireless settings
Engineer only
調校提醒　影響 GW 與 ED 的 BLE link 行為，可能改變延遲、穩定度與耗電。建議優先使用 Preset；不建議在巡視模式調整。
Preset（建議先用）
Responsive
偏低延遲，適合單裝置或近距離調校
Balanced
預設折衷，適合多數情境
Conservative
偏穩定，多裝置或干擾環境較佳
Advanced override
展開以手動指定 interval（不建議） ›
BLE units ≈ 30.0 ms
BLE units ≈ 50.0 ms
1 BLE unit = 1.25 ms（Bluetooth Core spec）
進階設定　覆寫 preset 後將直接寫入裝置；建議測試後再套用到生產。本頁僅處理 BLE connection interval，不處理 packet / throughput interval。
Apply path
App (Engineer) → CTRL.interval → GW → ED link param update
寫入目標為 CTRL.interval；不是 GW_CFG。GW_CFG 不持有 BLE connection interval 欄位。
