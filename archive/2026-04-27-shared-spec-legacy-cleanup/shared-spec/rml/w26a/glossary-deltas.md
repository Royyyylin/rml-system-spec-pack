# Glossary Deltas — W26A: Shift Reporting & Dashboard Customization

> Cross-links master glossary: `01_context-scope/ubiquitous-language.md`
> New terms introduced in App Wave 26A.

## New Terms

| Term | Definition | Canonical Location |
|---|---|---|
| `ShiftReport` | App domain model: report for a shift time window. Fields: `id`, `time_window`, `included_device_ids`, `generated_by`, `regeneration_params`, `sections`. | `lib/domain/models/shift_report.dart` |
| `ReportSection` | Sub-model within `ShiftReport`. Types: alert summary, telemetry highlights, status transition log, device health score summary. | `lib/domain/models/report_section.dart` |
| `ReportAggregationEngine` | Flutter isolate-based service. Queries local alert event log + telemetry history DB for a given time window. Produces `ShiftReport`. | `lib/services/report_aggregation_engine.dart` |
| `ShiftReportRepository` | App repository for persisting and loading `ShiftReport` objects from local storage. | `lib/data/repositories/shift_report_repository.dart` |
| `regeneration_params` | Serialized query parameters stored in `ShiftReport` to allow deterministic re-generation from raw data. | `ShiftReport` model field |
| `plain-text clipboard export` | Structured text summary of a report, suitable for pasting into messaging apps (Slack, LINE, etc.). Generated by App report UI, not Central. | `w26-01-shift-reports.md` §1a2 |
| `Dashboard customization` | App-local widget add/remove/reorder preference for the main monitoring dashboard. Not synchronized to Central or between devices. | `w26-02-dashboard-customization.md` |
| `custom widget layout` | Persisted App-side list of widgets and their display order in the customized dashboard view. | App preference store |

## Existing Terms Referenced

- `alert event log` — source data for shift reports; must exist from Wave 25A §1
- `telemetry history DB` — source data for shift reports; must exist from Wave 25A §2
- `RSSI / PDR / latency` — telemetry metrics included in report; see `glossary.md` wire terms

## Disambiguation

- `W26A` is an **App-internal planning wave** (not a cross-repo feature ID). It does not correspond to a firmware or Central wave.
- Report generation is **App-local** — compare with `Conductor/AI orchestration layer` which handles cross-repo planning. The shift report is a human-facing operational artifact, not a system governance document.
